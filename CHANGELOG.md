# Changelog

## [1.3.1] - 2026-03-15

### Changed
- Updated for Build 42.14 compatibility: increased versionMax

## [1.3.0] - 2026-03-15

### Changed
- Updated for Build 42.15 compatibility: translation files converted from Lua .txt format to .json

## [1.2.1] - 2025-12-16

### Added
- Multi-version support: added back support for Build 42.12.3 (and future 42.12.x versions) with separate support for Build 42.13+ builds

### Changed
- Default exhaustion penalty multiplier set to 0% for Build 42.13+ (discard is now cosmetic rather than XP source as it was in 42.12)

## [1.2.0] - 2025-12-13

### Changed
- Added compatibility with Build 42.13
- Restored discard via custom implementation (ported from 42.12)

## [1.1.0] - 2025-10-27

### Added
- Configurable endurance cost for discard actions (0-100% slider, default 50%)

## [1.0.0] - 2025-10-25

### Added
- Initial release
- One-click discard for forage icons via customizable mouse button (RMB default)
- Alternative context menu access via different mouse button (MMB default)
- Optional item tooltips on hover
- Support for RMB, MMB, MB4, MB5 button configurations
- Multilingual support: CN, DA, DE, EN, ES, FR, HU, IT, JP, KO, PL, PTBR, RU, TH, TR, UA
- Mod options menu for full customization
