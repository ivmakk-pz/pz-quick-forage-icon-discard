[ v1.0.0 - 2025-10-25 ]
Added:
- Initial release
- One-click discard for forage icons via customizable mouse button (RMB default)
- Alternative context menu access via different mouse button (MMB default)

- Support for RMB, MMB, MB4, MB5 button configurations
- Multilingual support: CN, DA, DE, EN, ES, FR, HU, IT, JP, KO, PL, PTBR, RU, TH, TR, UA
