# Quick Forage Icon Discard

A Project Zomboid mod for Build 42.

## Features

- Quick discard forage items by single mouse click (RMB by default)
- No context menu needed

## Installation

### Steam Workshop
1. Subscribe to the mod on Steam Workshop
2. Enable in Mods menu
3. Start/load game

### Manual Installation
1. Extract to `%USERPROFILE%\Zomboid\mods\`
2. Enable in Mods menu

## Requirements

- Project Zomboid Build 42.9+

## Usage

Right-click (by default) on forage item icons to quickly discard them without opening the context menu.
