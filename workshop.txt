title=Quick Forage Icon Discard [B42]
description=The mod adds a single mouse click to discard.
description=
description=Tired of opening context menus every time you want to discard foraged items? This mod lets you quickly discard forage icons with a single mouse click, saving you time and making foraging more efficient.
description=
description=[h2]Motivation[/h2]
description=
description=The vanilla foraging context menu looks overwhelming when I only need the discard action. Since foraged items are automatically added to your active container, there's no value in selecting containers through the context menu. I loved the concept of [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3571757687]Forage Icon Extension[/url], however I found that interacting with the entire icon is much easier than aiming for a tiny discard button, especially when zoomed out.
description=
description=[h2]Key Features[/h2]
description=
description=[list]
description=[*]One-Click Discard: Discard foraged items instantly with a single mouse button press (Right Mouse Button by default)
description=[*]Fully Customizable Controls: Configure both discard and context menu buttons independently. Choose from Right Mouse Button, Middle Mouse Button, or Side Buttons (MB4/MB5)
description=[*]Optional Item Tooltips: Item name tooltips on hover
description=[*]Context Menu Still Available: Reassign context menu to a different mouse button (Middle Mouse Button by default)
description=[*]Translations: CN, DA, DE, EN, ES, FR, HU, IT, JP, KO, PL, PTBR, RU, TH, TR, UA
description=[/list]
description=
description=
description=[h2]Mod Options[/h2]
description=
description=You can customize the behavior of this mod via mod options: Menu / Options / Mods / Quick Forage Icon Discard.
description=
description=[h3]Available Options[/h3]
description=[list]
description=[*]Discard Button: Choose which mouse button performs quick discard (Default: Right Mouse Button)
description=[*]Context Menu Button: Choose which mouse button opens the context menu (Default: Middle Mouse Button)
description=[*]Show Item Tooltip: Toggle item name tooltips when hovering over forage icons (Default: Enabled)
description=[/list]
description=
description=[h2]Compatibility[/h2]
description=[list]
description=[*]Build 42.12+
description=[*]Safe to add/remove mid-game
description=[*]Minimal vanilla code patched for better compatibility and stability
description=[*]Recommended with [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3507997225]Foraging Tooltip Extended [B42][/url]
description=[/list]
description=
description=[h2]Known Issues & Limitations[/h2]
description=[list]
description=[*]You can't assign the same mouse button for both discard and context menu actions (only the Discard button will be active)
description=[*]Dropped items (e.g., twigs or wood splinters after cutting trees, chicken eggs or feathers, or manually dropped items) still use the default RMB for the context menu and can't be discarded. This mod only affects foraged items.
description=[/list]
