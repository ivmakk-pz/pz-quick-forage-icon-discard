title=Quick Forage Icon Discard [B42]
description=One-click discard for foraged items - faster foraging without the context menu.
description=
description=[h2]Motivation[/h2]
description=The vanilla foraging context menu looks overwhelming when I only need the discard action. Since foraged items are automatically added to your active container, there's no value in selecting containers through the context menu. I loved the concept of [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3571757687]Forage Icon Extension[/url], however I found that interacting with the entire icon is much easier than aiming for a tiny discard button, especially when zoomed out.
description=
description=[b]Build 42.13 NOTE:[/b] The vanilla game removed the discard feature in Build 42.13+. This mod brings the discard feature back using the implementation from B42.12, making it accessible via mouse button binding (right-click by default).
description=
description=[h2]Key Features[/h2]
description=[list]
description=[*][b]One-Click Discard[/b]: Discard foraged items instantly with a single mouse button press
description=[*][b]Context Menu Still Available[/b]: Reassign context menu to a different mouse button or fully disable it
description=[*][b]Translations[/b]: CN, DA, DE, EN, ES, FR, HU, IT, JP, KO, PL, PTBR, RU, TH, TR, UA
description=[/list]
description=
description=[h2]Mod Options[/h2]
description=Configure the mod via: Menu / Options / Mods / Quick Forage Icon Discard
description=
description=[h3]Available Options[/h3]
description=[list]
description=[*][b]Discard Button[/b]: Choose which mouse button performs quick discard (Default: Right Mouse Button)
description=[*][b]Context Menu Button[/b]: Choose which mouse button opens the context menu (Default: Middle Mouse Button)
description=[*][b]Show Item Tooltip[/b]: Toggle item name tooltips when hovering over forage icons (Default: Enabled)
description=[/list]
description=
description=[h2]Compatibility[/h2]
description=[list]
description=[*]Supported builds: 42.15+ (tested on 42.20.2 SP & MP)
description=[*]Safe to add/remove mid-game
description=[*]Multiplayer: Supported
description=[*]Recommended with [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3507997225]Foraging Tooltip Extended [B42][/url]
description=[/list]
description=
description=[h2]Known Issues & Limitations[/h2]
description=[list]
description=[*]You can't assign the same mouse button for both discard and context menu actions (only the Discard button will be active)
description=[*]Dropped items (e.g., twigs or wood splinters after cutting trees, chicken eggs or feathers, or manually dropped items) still use the default RMB for the context menu and can't be discarded. This mod only affects foraged items.
description=[/list]
