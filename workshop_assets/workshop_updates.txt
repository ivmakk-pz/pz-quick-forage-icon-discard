# Workshop Update History

v1.2.1 - 2025-12-16

Added:
- Multi-version support: added support for Build 42.12.x and 42.13+
- Game automatically loads appropriate version based on player's build

v1.2.0 - 2025-12-13

Changed:
- Added compatibility with Build 42.13
- Restored discard via custom implementation (ported from 42.12)

v1.1.0 - 2025-10-27

Added:
- Configurable endurance cost for discard actions (0-100%, default 50%)

v1.0.0 - 2025-10-25

Added:
- Initial release
- One-click discard for forage icons via customizable mouse button (RMB default)
- Alternative context menu access via different mouse button (MMB default)
- Optional item tooltips on hover
- Support for RMB, MMB, MB4, MB5 button configurations
- Multilingual support: CN, DA, DE, EN, ES, FR, HU, IT, JP, KO, PL, PTBR, RU, TH, TR, UA
- Mod options menu for full customization
